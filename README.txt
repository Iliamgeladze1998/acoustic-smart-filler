ACOUSTIC SMART FILLER — package layout
======================================

  acoustic_smart_filler\
    SETUP.vbs                 ← double-click this (visual setup window)
    SETUP.bat                 ← same as SETUP.vbs (no CMD UI)
    setup_wizard.py           ← Setup window program
    CreateDesktopIcon.vbs     ← desktop shortcut helper
    README.txt
    App\                      ← ALL program files and data


FIRST TIME
----------
1. Install Python 3 from python.org (tick "Add to PATH").
2. Double-click SETUP.vbs  (Windows window — not Command Prompt)
3. Click “Run setup” in the wizard
4. Open App\config.json and paste your OpenAI API key
5. Use the Desktop icon: Acoustic Smart Filler


DAILY USE
---------
Desktop icon → special Chrome + Smart Filler.

Single product: open product edit → Scrape → review → Fill page.
Bulk: product list → tick rows → Bulk tab → Import → Scrape queue → review → Fill approved.
Never auto-saves (Save only in CS-Cart).
