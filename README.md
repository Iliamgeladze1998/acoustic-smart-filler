# Acoustic Smart Filler

აპლიკაცია acoustic.ge ადმინ პანელისთვის — ავტომატურად გენერირებს პროდუქტის ინფორმაციას AI-ით და ავსებს ფორმას.

---

## რა აკეთებს აპლიკაცია

1. **უკავშირდება Chrome-ს** — debug რეჟიმში გახსნილ Chrome-თან (port 9222)
2. **სკანირებს პროდუქტის გვერდს** — კითხულობს სათაურს, ფასს, კატეგორიებს, მახასიათებლებს
3. **ეძებს ინფორმაციას ინტერნეტში** — DuckDuckGo-ს გამოყენებით პოულობს რეალურ სპეციფიკაციებს
4. **AI გენერირებს კონტენტს** — OpenAI (GPT) წერს ქართულად:
   - სრული აღწერა (HTML, სპეციფიკაციებით)
   - პრომო ტექსტი
   - SEO ველები (page title, meta description, meta keywords)
   - კატეგორიები (არსებული კატალოგიდან)
   - მახასიათებლები (ბრენდი, მდგომარეობა და სხვა)
   - ვიდეო URL (YouTube)
   - ტეგები
   - old_price (თუ ფასი < 100 GEL)
5. **ავსებს ფორმას** — ყველაფერს აწერს პროდუქტის ედიტ ფორმაში
6. **არ აწვებს Save-ს** — შენ თავად გადაამოწმებ და დააჭერ Save-ს

### ნაბიჯი 3 — OpenAI API key

1. გადადი [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
2. დააჭირე **Create new secret key**
3. დააკოპირე key (იწყება `sk-`-ით)

API key შეიყვანე აპლიკაციის ინტერფეისში:
- გაუშვი აპლიკაცია
- ზედა პანელში დაინახავს **"API key"** ველს
- ჩაწერე შენი key
- დააჭირე **Save settings**

ან ხელით — გახსენი `App/config.json` და ჩაწერე:
```json
{
  "openai_api_key": "sk-შენი-key-აქ",
  "openai_model": "gpt-4o-mini",
  "content_language": "Georgian"
}
```

> **მნიშვნელოვანი:** API key არ არის რეპოში (`.gitignore`-ის გამო). ის რჩება მხოლოდ შენ კომპიუტერზე.

## გამოყენება

### ერთი პროდუქტი

1. Chrome-ში გახსენი პროდუქტის ედიტ გვერდი (`products.update`)
2. აპლიკაციაში დააჭირე **Scrape**
3. გადახედე გენერირებულ კონტენტს ჩანართებში:
   - **Texts** — აღწერა, პრომო, SEO
   - **Images** — სურათების ძიება და ატვირთვა
   - **Categories** — კატეგორიების არჩევა
   - **მახასიათებლები** — ბრენდი, მდგომარეობა
   - **Video** — YouTube ვიდეო
4. დააჭირე **Fill page** — ავსებს ფორმას
5. Chrome-ში გადაამოწმე და დააჭირე **Save**

### ბევრი პროდუქტი (Bulk)

1. Chrome-ში გადადი **Products** სიაზე
2. მონიშნე პროდუქტები (checkbox-ები)
3. აპლიკაციაში **Bulk** ჩანართი → **Import from Chrome list**
4. დააჭირე **Scrape queue** — დაამუშავებს ყველას
5. გადახედე თითოეულს, **Approve** რომელებიც გინდა
6. დააჭირე **Fill approved** — ავსებს ყველა დამტკიცებულს
7. Chrome-ში თითოეული გადაამოწმე და დააჭირე Save

## კატეგორიის არჩევა (ჭკვიანი მატჩინგი)

აპლიკაცია იცნობს პროდუქტის ტიპს სათაურიდან და აირჩევს სწორ კატეგორიას:

| პროდუქტის ტიპი | სწორი კატეგორია | არასწორი (არ აირჩევს) |
|----------------|-----------------|----------------------|
| ელექტრო გიტარა | ელექტრო | ბასი, აკუსტიკური, ხელსაწყოები |
| ბას გიტარა | ბას-გიტარა | ელექტრო, აქსესუარები |
| ბას კაბინეტი | გამაძლიერებელი/კომბი | ბას-გიტარა |
| მიკროფონი | მიკროფონები | ვოკალის პროცესორი, კაბელი |
| გიტარის ეფექტი | ეფექტები | ელექტრო (რადგან "Electro" ბრენდია) |
| კლავიშის სადგამი | კლავიშის | აქსესუარები, სინთეზატორი |
| მიქსერი | მიქსერი | გიტარა, მიკროფონი |

**FINA** კატეგორია ავტომატურად ემატება ყველა პროდუქტს, თუ არსებობს კატალოგში.

## რა ველებს ავსებს

| ველი | აღწერა |
|------|--------|
| **product_name** | სათაურის გასწორება (კაპიტალიზაცია, ფორმატი) |
| **price** | ინახება გვერდზე არსებული ფასი |
| **old_price** | თუ ფასი < 100 GEL, ავტომატურად ივსება |
| **tags** | 3-8 ქართული ტეგი, მძიმე გამყოფით |
| **full_description** | სრული აღწერა HTML-ში (intro + specs + უპირატესობები) |
| **promo_text** | მარკეტინგული ტექსტი |
| **page_title** | SEO title (50-65 სიმბოლო) |
| **meta_description** | SEO description (140-160 სიმბოლო) |
| **meta_keywords** | SEO keywords (ქართული) |
| **seo_name** | Latin slug |
| **categories** | 1-3 კატეგორია არსებული კატალოგიდან |
| **features** | ბრენდი, მდგომარეობა და სხვა მახასიათებლები |
| **videos** | YouTube ვიდეო URL + ქართული სათაური/აღწერა |
